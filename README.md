## 演艺履历概览

- **童星与学生时期**：6 岁起学习音乐剧并开始童星工作；小学至高中持续参加广播委员与广播社团，具备扎实的发声与台词表现力。
- **舞台剧时期（渚志帆名义）**：20 岁之后以「渚志帆」名义活跃于日本舞台剧领域，积累了丰富的戏剧演出经验。
- **2022年10月（自由身与写真影像）**：圆满退所转为自由身，开始以「十束るう」名义发行个人写真影像作品（Image Video）；同年 12 月因颈椎症恶化辞演原定告别舞台并休养。
- **2023年7月–8月（艺名统一与跨界转型）**：7 月 31 日宣布将全部演艺活动名义统一为「十束るう」；8 月于周刊杂志公开全裸写真，并于 8 月 30 日宣布正式跨界进入成人影视行业，担任 SOD Create、Attackers 等厂牌专属艺人。
- **2024年至今（多栖发展）**：在持续推出影像、VR 与数字写真集的同时，亦参演 TBS《极度不妥！》（不適切にもほどがある!）及日本电视台《无法消除的我》等主流日剧。

## 作品与活动分类

- **主流电视剧**：TBS《极度不妥！》（不適切にもほどがある!）、日本电视台《无法消除的我～持续炎上的数字纹身～》
- **影像作品**：SOD Create、Attackers 等厂牌专属单体作品、VR 及配信限定系列
- **写真出版**：个人写真影像 DVD（Image Video）及数字写真集

## 部署到 GitHub Pages 方法

1. 在 GitHub 新建公开仓库（例如 `totsuka-ruu-wiki`），将本目录下的 `index.html` 和 `README.md` 上传至仓库根目录。
2. 进入仓库 **Settings → Pages → Build and deployment**，将 Branch 设为 `main` / `/ (root)` 并保存。
3. 等待 1～2 分钟即可通过 `https://<你的用户名>.github.io/totsuka-ruu-wiki/` 访问完整暗黑百科单页。
